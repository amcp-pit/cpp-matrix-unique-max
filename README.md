# Уникальный максимум
В произвольной матрице целых чисел из файла найти максимальный из уникальных 
(т.е. максимальный из тех, значения которых не повторяются в массиве) и вывести на экран. 
Если такого элемента нет, то вывести `empty`.

Имя файла с матрицей задано в командной строке.

## Требования
Программа не должна использовать контейнеры STL (std::vector, std::string и т. д.). 

## Формат файла
Формат файла, в котором записана входная матрица:

* в первой строке файла указаны два целых числа через пробел: количество строк и количество столбцов матрицы;
* во второй строке и далее записаны элементы матрицы по строкам.
